# Third-party software and acknowledgments

The CTFd core theme in local/theme is derived from CTFd 3.7.7. Custom Northstar templates and styles modify that base. Retain the upstream license in licenses/CTFd-LICENSE. Upstream: https://github.com/CTFd/CTFd/tree/3.7.7 . The bundled theme contains upstream JavaScript, icons and fonts; retain embedded notices. It includes Font Awesome, Lato and Raleway assets, and the existing CTFd client bundles. No claim of student authorship is made for these components.

Deployment uses Docker/Compose, CTFd, MariaDB, Redis, Nginx, Python, Gunicorn, OpenSSH and Flask. Local preview also uses Waitress. Evidence generation uses Pillow; tests use pytest, PyYAML and PyFatFS. Forensic validation used Sleuth Kit. Dependency versions are in requirements*.txt and Compose image tags. The original design also references VirtualBox/Ubuntu; these are not supplied VM images.

References: https://docs.ctfd.io/ ; https://docs.docker.com/ ; https://flask.palletsprojects.com/ ; https://pillow.readthedocs.io/ ; https://www.sleuthkit.org/ ; https://github.com/CTFd/CTFd . Original design references are retained in the supplied group report. Binary evidence is fictional and generated by build.py.
